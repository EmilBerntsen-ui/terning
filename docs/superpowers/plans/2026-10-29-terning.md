# Terning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A normal-looking dice app (1–6 dice), installed on the phone's home screen, that rolls fairly on a one-finger tap. A two-finger tap secretly lands one die on 6, and a three-finger tap lands every die on 6.

**Architecture:** A static web app (plain HTML, CSS and ES modules, no bundler) published to GitHub Pages and installed as a PWA, the same way as `ironman-2027`. The pure logic (dice, gesture tracking, saved settings) lives in small modules tested with `node --test`. `app.js` only wires them to the DOM. `node build.mjs` copies `src/` and `assets/` to `dist/site/` and stamps the service worker with a content hash so the phone picks up each new version.

**Tech Stack:** HTML/CSS/JS (ES modules), Pointer Events, Service Worker + Web App Manifest, Node 24 (`node --test`, `node:zlib`, `node:crypto`), GitHub Actions + GitHub Pages.

**Spec:** None. The user skipped the design questions. Requirements come from the conversation:
- Board-game nights with friends who also roll on the phone.
- Works like a normal dice app, with 1–6 dice.
- With one die, a two-finger tap rolls 6.
- With more than one die, two fingers make one die a 6 and three fingers make all dice 6.
- Spend no money.

Everything else below is the planner's call.

## Global Constraints

- Zero dependencies (runtime and dev). Node ≥ 20.15. Tests run with `node --test`.
- No money: public repo, GitHub Pages and Actions on public repos are free. Nothing paid, no Apple developer account.
- Nothing a friend can see hints at the trick. Home-screen name `Terning`, repo `terning`, URL `https://emilberntsen-ui.github.io/terning/`. These words never appear in `index.html` or `manifest.webmanifest`: fake, cheat, rigged, forced, snyd, falsk. Code identifiers may say `forced`.
- A forced roll and a fair roll must be indistinguishable: same number of tumble frames, same timing, same CSS, random tumble faces in both. Only the final faces differ.
- Fair faces come from `crypto.getRandomValues` with rejection sampling. Never `Math.random`.
- Gesture rule: the tap counts the most pointers down at the same time during one gesture. It rolls when the last pointer lifts. A cancelled gesture (`pointercancel`) doesn't roll. Taps during a running roll are ignored.
  - 1 finger → fair.
  - 2 fingers → exactly one die is forced to 6, in a random position. The other dice stay fair, so they can also show 6.
  - 3+ fingers → every die is 6.
  - With one die, 2 and 3 fingers both give 6.
- Dice count 1–6, default 1, changed with − / + buttons outside the roll area, remembered in `localStorage` under key `terning-count`. Every storage access is in try/catch.
- When there's more than one die, show the sum under the dice.
- Relative URLs only (the site is served from `/terning/`).
- Target: iPhone Safari, installed to the home screen (a guess based on the ironman guides). Android Chrome should work with the same code. A two-finger tap must never zoom, scroll or select text.
- Colours: felt background `#0F3D2E`, die `#FAFAF7`, pips `#1A1A1A`, text `#E8F0EC`. Theme colour `#0F3D2E`.
- Not in v1: shake to roll, sound, haptics, roll history.

### Task 1: Project scaffold and dice logic

**Files:**
- Create: `package.json`, `.gitignore`, `src/dice.js`
- Test: `test/dice.test.mjs`

**Interfaces:**
- Produces:
  - `export const MIN_DICE = 1, MAX_DICE = 6, TUMBLE_FRAMES = 8, FRAME_MS = 70;`
  - `randomInt(n: number, randomByte?: () => number): number`. Returns 0..n-1 for 1 ≤ n ≤ 256. The default draws one byte via `crypto.getRandomValues(new Uint8Array(1))`. Bytes ≥ `256 - (256 % n)` are rejected and redrawn. Otherwise it returns `byte % n`.
  - `sixesFor(fingers: number, count: number): number`. Returns 0 if fingers < 2, 1 if fingers === 2, and `count` if fingers ≥ 3.
  - `planRoll(count: number, opts?: { sixes?: number }, rand?: (n: number) => number): { frames: number[][], final: number[] }`.
    - `count` is clamped to 1..6, and `rand` defaults to `randomInt`.
    - Always `TUMBLE_FRAMES` frames of `count` faces, each `rand(6) + 1`.
    - `final` is `count` faces `rand(6) + 1`. Then `min(sixes, count)` distinct positions are set to 6, picked by a partial Fisher–Yates over `[0..count-1]` (step `i` swaps with `i + rand(count - i)`).

  assert.equal(randomInt(6, bytes([251])), 5);

  assert.equal(sixesFor(1, 3), 0);
  assert.equal(sixesFor(2, 1), 1);
  assert.equal(sixesFor(2, 4), 1);

  assert.equal(sixesFor(5, 2), 2);

test('fair roll takes every face from the source', () => {
  const r = planRoll(3, {}, () => 3);
  assert.equal(r.frames.length, TUMBLE_FRAMES);
  assert.deepEqual(r.final, [4, 4, 4]);

test('one forced six lands where rand puts it, the rest stay fair', () => {

  assert.deepEqual(r.final, [1, 1, 6, 1]);

test('all sixes; the tumble is unaffected', () => {

  assert.deepEqual(r.final, [6, 6, 6]);
  assert.equal(r.frames.length, TUMBLE_FRAMES);
  assert.ok(r.frames.every(f => f.length === 3 && f.every(v => v === 1)));
  assert.deepEqual(planRoll(2, { sixes: 5 }, () => 0).final, [6, 6]);
});
test('count is clamped to 1..6', () => {

  assert.equal(planRoll(9, {}, () => 0).final.length, 6);
});
test('default source is roughly uniform', () => {

});

### Task 2: Gesture tracker and saved dice count

**Files:**
- Create: `src/gesture.js`, `src/prefs.js`
- Test: `test/gesture.test.mjs`, `test/prefs.test.mjs`

**Interfaces:**
- Produces:
  - `createTapTracker(): { down(id: number): void, up(id: number): { fingers: number } | null, cancel(id: number): void }`. It tracks the pointer ids that are down and the most that were down at once. `up` returns `{ fingers }` only when the last pointer lifts, then resets. `cancel` removes the id and marks the gesture aborted, so the gesture's final `up` returns `null`. The tracker resets once no pointers are down. An unknown id in `up` returns `null`.
  - `loadCount(storage?): number` and `saveCount(n: number, storage?): void`. Key `terning-count`. `storage` defaults to `globalThis.localStorage`, resolved *inside* the try so a throwing getter is caught. `loadCount` parses an int, clamps it to 1..6, and falls back to 1 on missing or invalid data or any throw. `saveCount` swallows errors.
